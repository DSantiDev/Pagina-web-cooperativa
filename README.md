# COOVITEL web independiente

## Ejecutar localmente

1. Instala Node.js LTS.
2. Abre esta carpeta con Visual Studio Code.
3. Ejecuta `npm install`.
4. Ejecuta `npm run dev` y abre la dirección indicada en la terminal.

## Preparar para publicar

Ejecuta `npm run build`. Vite creará la carpeta `dist` con los archivos estáticos para un hosting web.

## Páginas integradas

- `/productos`
- `/` (Home)
- `/quienes-somos`
- `/confianza`
- `/asociate`
- `/beneficios`

Antes de convertir el proyecto a tema WordPress, se consolidarán el header y footer compartidos y se reemplazarán los recursos temporales por los definitivos.
