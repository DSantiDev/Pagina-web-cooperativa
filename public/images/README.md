# Imágenes locales

Guarda aquí las imágenes que se usarán en el sitio. Para asignar una imagen al slider desde `src/lib/media.ts`, usa una ruta pública:

```ts
src: "/images/nombre-de-la-imagen.jpg"
```

No se requieren importaciones. Los formatos recomendados son WebP, JPG o PNG; para el slider, utiliza imágenes verticales con una proporción cercana a 1080 × 1350 px.
